# EARLYWINE PRESIDENTIAL BLUEPRINT

Public GitHub Pages landing surface for **The Earlywine Blueprint** by Robert M. Earlywine-Lucas (Lokivelli).

## Deployment

GitHub Pages should publish from:

- Branch: `main`
- Folder: `/ (root)`
- Entry file: `index.html`

The page is intentionally static: no framework, no build step, no Jekyll dependency.

## Status

Public civic systems presentation. Proposals, targets, planning assumptions, legal mechanisms, costs, and engineering claims remain subject to sourcing, pilot evidence, independent review, and correction.

## Media

The address has been published separately on YouTube, Facebook, and TikTok. Exact public URLs can be wired into `index.html` once frozen so the Pages URL becomes the single durable front door.
